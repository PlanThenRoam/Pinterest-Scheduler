Opening, privacy and limitations

This is one self-contained HTML file, not an installed Android APK. Open it in a full browser. Android file managers and document viewers vary; some do not run HTML applications or allow video downloads. No script can override those restrictions. The export test checks the current browser before you spend time editing.

No external libraries, fonts, image downloads, analytics, network calls, accounts or keys. Copy/settings may be saved locally when the browser permits it. Photo selection is local, not a server upload. Use Save project for a portable copy including the pictures.

There are twenty-eight designed visual systems plus a large selectable effects library. Effects are deterministic local canvas effects rather than cloud AI filters. You can edit scene copy, prompts, text positions, camera motion, transitions, text entrances, framing, overlays, atmosphere, per-scene text colour and adaptive readability. This does not alter your Windows Remotion engine.
