# Bundled Google Fonts

Unmodified files from [Google Fonts](https://github.com/google/fonts/tree/809e4d8b8d7e9364a914909bb777679606c178b8). Each directory retains its licence and catalogue metadata. `font-manifest.mjs` records hashes, official catalogue weights, internal weight classes, actual styles/axes and the complete Unicode character map for every file. Rebuild with `python composer/bundle-google-fonts.py /path/to/google-fonts`. No synthetic bold, synthetic italic or system substitution is permitted.
